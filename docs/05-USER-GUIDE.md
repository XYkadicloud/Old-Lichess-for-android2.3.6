## 二、你要准备的东西

- 手机：Samsung GT-S5360（Galaxy Y），Android 2.3.6
- 一根数据线（或用蓝牙 / 手机浏览器下载）
- 手机能连 Wi-Fi
- 一个 Lichess 账号（免费注册：lichess.org）
- **一个 Lichess API 令牌**，怎么弄：

  1. 用电脑浏览器登录 lichess.org
  2. 打开这个网址：`https://lichess.org/account/oauth/token`
  3. 点新建令牌，勾上 **Play games with the board API**（board:play），可以再勾一个读取账号信息
  4. 复制那串 `lip_` 开头的字符

  ⚠️ **这个令牌不要发给任何人，也不要贴到和我的聊天里。** App 装好后，在手机上的输入框里填，它只存在你手机本地。

## 三、手机上装 APK 的步骤

1. 手机：`设置` → `应用程序` → 勾选 **未知来源**
2. 用手机上的文件管理器打开 `存储卡/lichess/LichessOld-0.5.0.apk`
3. 点 `安装`
4. 以后更新：直接覆盖安装（签名一样）。**如果提示签名冲突**，就先卸载旧版再装（会丢失设置，要重新输令牌）

### 「排位赛」和「休闲赛」有什么区别

下棋之前会让你选：

- **排位赛（计分）** —— 赢了加分、输了扣分。分数就是主页上那些数字，
  每个分项（子弹棋 / 闪电棋 / 快速棋 / 经典棋 / 通信棋 / 各种变体 / 谜题）**各自独立算分**。
- **休闲赛（不计分）** —— 随便下，分数不动。**第一次测试建议选这个。**
- **和电脑下永远是休闲**，不会加减分。

⚠️ **用「找真人对手」最快只能选 8+0（8 分钟）**。这是 Lichess 服务端的限制
（Board API 只允许快速棋及更慢的棋），不是 App 的 bug。
想下 1+0、3+0 这种快棋，请用「**挑战玩家**」—— 输入对方用户名，那边可以选快棋。

### 怎么看别人的主页

1. 进入一局在线对局（或者从「观战」里点开一局）
2. 点屏幕上方那一行对手的名字
3. 就能看到对手的等级分和战绩；底部还有「**挑战 TA**」按钮，可以直接约棋

## 六、怎么把日志给我

App 里有两个功能：

- **「运行日志」页面**：直接显示最近的运行记录 → 拍照 / 截图发我
- **「保存到存储卡」按钮**：把日志写到 `存储卡/LichessOld/log.txt`
  → 数据线连电脑，选「USB 存储」模式 → 把 `LichessOld` 文件夹拷出来发我

**网络出问题时**：先去「网络诊断」点「开始诊断」，那一页会逐步骤告诉你卡在哪
（DNS / TCP / TLS 握手 / 证书校验 / HTTP），拍照给我最有价值。

**闪退时**：App 下次打开会自动弹出「上次崩溃报告」，拍照或保存后发我。

日志里的令牌会自动变成 `***`。但你发我之前扫一眼，看到 `lip_` 开头的一串就删掉那行，保险。

## 七、常见问题

**Q：我需要在自己电脑上装开发软件吗？**
A：不需要。工具链装在项目盘，编译我来做，你只管装 APK 和测。

**Q：为什么第一次联网要等几秒？**
A：你的手机是 2011 年的 832MHz 单核处理器，TLS 握手要在纯 Java 里做椭圆曲线验签。
第一次连上之后同一条连接会复用，后面的请求就快了。

**Q：为什么提示证书错误？**
A：先检查手机的日期时间对不对。时间偏差太大，证书会被判成"还没生效"或"已过期"。
诊断页会明确告诉你证书的有效期和手机当前时间。

**Q：会不会偷偷关掉证书校验让程序「看起来能连」？**
A：不会。规格书第 I.7 条明确禁止，我也不会做。关掉证书校验等于把你所有流量暴露给任何人。
我用了一个更强的验证方式：测试里故意把证书签名改一个 bit，程序必须拒绝 —— 这个测试是通过的。

**Q：我的令牌会离开手机吗？**
A：不会。令牌只存在手机本地，只用于给 lichess.org 发请求时带上。
**唯一**的例外是万一 TLS 自实现彻底失败需要走「中转服务器」——那必须先得到你明确同意。

**Q：离线 AI 有多强？**
A：业余水平。它是我自己写的 alpha-beta 搜索引擎（搜索深度 6 + 静态搜索），
不是 Stockfish。你手机的算力也跑不动 Stockfish。等级 1~3 适合随便玩玩，7~8 要认真下。
