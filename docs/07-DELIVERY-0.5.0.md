| TLS 1.2 握手 + SNI + 密码套件协商 | `TLS 1.2 / ECDHE-ECDSA-AES128-GCM-SHA256` |
| 真实证书链校验 | 链长 3，锚在真实的 `ISRG Root X2`，主机名匹配，验签 174ms |
| ECDSA + RSA 两条验签路径 | 都走到了（链上两种签名算法都有） |

## 五、已知限制

1. **首次联网握手要几秒。** GT-S5360 是 832MHz 单核 ARM11，TLS 握手要在纯 Java 里
   做 ECDSA 验签。之后同一条连接会复用 20 次，不会每次都等。
2. **手机时间必须准确。** 时间偏差超过证书有效期，TLS 会失败。诊断页会明确提示。
3. **在线对局的界面比较朴素。** 没有走子历史列表、没有声音、没有动画。
   先把功能跑通，好看的东西后面再说。
4. **观战只能看焦点对局**，不能自己挑频道。
5. **离线 AI 最强只到"业余水平"。** 它是自写的 alpha-beta 引擎（深度 6 + 静态搜索），
   不是 Stockfish。GT-S5360 的算力也跑不动 Stockfish。
6. **没有对局历史回放。** `/api/games/user/{me}` 的接口已经封装好了（`LichessApi.gamesPgn`），
   但界面还没做。
